# Viqui Bakery · Tienda (repo público)
Sitio estático. Lee el menú directo de Supabase con la clave pública (solo lectura); ver `js/config.js`.
Si la base de datos está vacía o no responde, muestra el menú de `js/products.js`.
No necesita variables de entorno en Vercel.
Las imágenes viejas viven en `imagenes/`; las nuevas que subas desde el panel se guardan en Vercel Blob.
